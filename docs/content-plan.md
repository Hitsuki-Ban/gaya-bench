# テストシナリオ カバレッジ計画 (v1.2)

目標: **15シーン / 各3〜4キャラ / 計約155セリフ**。TTSモデルの「ガヤ適性」を多角的に観測できる構成にする。

## 観測したい軸

1. **声の多様性**: 性別 × 年齢帯 (child〜elderly) × 役柄 — モブらしい声の幅が出せるか
2. **感情・演技**: 12種のemotion × intensity — 演じ分けと感情の自然さ
3. **難所耐性** (`difficulty: hard`): 叫び / 笑い混じり / 囁き / 酔い / フィラー・感嘆詞 / 方言風の崩し / 子供声
4. **短文適性**: ガヤは1〜3秒の一言。短文で不自然にならないか (頭切れ・尻伸び・棒読み)
5. **文化圏レジスタ** (v1.1追加): ファンタジー以外の街の空気を声で出せるか — 中華街レトロ (中国語風語彙の発音: 焼売・老酒・飲茶など)、欧米大都市 (洋風の情景・外来語まじり)。**セリフ言語はすべて日本語**
6. **ガヤの型**: 呼び込み・掛け声型 / 住人の雑談型 (会話の輪) / 通行人のざわつき型 (すれ違いの断片) — walla素材としての性格の違い
7. **非人間声質** (v1.2追加): 機械 (意図的な棒読み・等間隔・定型アナウンス・音飛び) / 魔物 (片言・唸り・ダミ声) / 精霊 (極端な高低音・囁き・歌うような発話)。「自然さに最適化されたTTSが、制御された不自然さ・人外の声を出せるか」という逆方向の観測軸

### 非人間キャラの表記規約 (v1.2)

- スキーマの `gender` / `age` は**「聞こえ上の声質」**として指定する (例: 幼い声の妖精 = neutral × child)。`voice` フィールドに人外である旨と声の作り方を必ず記述する
- シーンの `tags` に `nonhuman` + 系統タグ (`machine` / `creature` / `spirit`) を付ける
- 将来 `character.kind` フィールドをスキーマに追加予定 (Codex連携チケット)。追加後にtags方式から移行する

## キャラ配分のガイド

- 全体で child / teen / elderly を最低それぞれ2キャラ確保 (高難度の声域)
- 男女比はほぼ半々、neutral (性別を特定しない声) も1〜2体入れる
- 役柄の重複を避ける (給仕・商人・衛兵・農夫・冒険者・受付・神官・子供・老人・傭兵・酔客・旅人...)

## 制作フロー

1. Director がシーンごとの下書きをSonnet 5サブエージェントで複数案生成 (数打ち)
2. Director が選別・リライトしてスキーマ準拠YAMLに整理
3. `gaya validate` を通してコミット (PR)。以後の追加シーンも同フローで随時追加可能

## 追加シナリオの拡張性

- 新シーン = YAMLファイル1個の追加でベンチ項目が増える (パイプライン・サイトは自動追従)
- 将来 (M6): 人間の走り書きト書き → LLMがスキーマ準拠YAMLに構造化・補完するCLIフローを追加
