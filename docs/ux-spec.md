# ベンチサイト UX仕様 (v1)

コンセプト: **聴き比べの摩擦を最小化する**。1クリック / 1キーで次の比較対象へ。
「たくさん聴く」行為が主役なので、再生のテンポと現在位置の明瞭さを何より優先する。

## 主要ビュー

### 1. 比較マトリクス (メインビュー)

- **行 = セリフ** (シナリオ → キャラでグルーピング)、**列 = モデル**
- セル = 再生チップ。クリック即再生。再生中はハイライト + プログレス表示。生成失敗/未生成セルは明示
- 行ヘッダ: キャラ名 / セリフテキスト / emotionタグ / difficultyバッジ
- 列ヘッダ: モデル名 + capabilityバッジ (感情対応・声質プロンプト・クローン・非言語音) + 列の表示ON/OFF
- **キーボード操作** (最重要):
  - `←` `→` 同一セリフの隣モデルへ移動+再生 / `↑` `↓` 次・前のセリフへ
  - `Space` 再生・停止 / `Enter` 連続再生開始
- **連続再生モード**: 行方向 (同一セリフをモデル横断で連続) / 列方向 (同一モデルでシーン通し聴き)。再生間に短い無音を挟む
- 同時再生は常に1クリップのみ

### 2. シナリオビュー

- シーン説明 (`scene.setting`) + キャラカード (`voice` / `personality` 表示) + 当該シーンの全セリフ
- ベンチの前提 (正規化・変換の方針) を明示するインフォボックス

### 3. A/Bブラインドモード

- 同一セリフ・ランダム2モデルをモデル名を隠して提示 → 好みを投票
- 結果はlocalStorageに集計し「自分の耳ランキング」を表示。十分な投票数までモデル別勝率は隠す

### 4. モデル詳細ページ

- バージョン / ライセンス / 生成パラメータ / capability / 生成速度 (RTF) / 特記事項
- そのモデルの全クリップ一覧

## フィルタと状態

- フィルタ: シナリオ / キャラ属性 (gender・age) / emotion / difficulty / モデル
- **表示状態はURLクエリに反映** (特定の比較状態を共有できる)

## 音声まわり

- 全クリップはパイプラインでラウドネス正規化済み (-18 LUFS) である前提。その旨をUIに明記
- opus再生 (全モダンブラウザ対応)。表示範囲のクリップをprefetch、それ以外は遅延ロード
- モバイル: マトリクスは横スクロールではなく「セリフ単位カード + モデル切替タブ」に組み替える

## デザイントーン

- ダーク基調 (オーディオツール/RPG感)、アクセント1色、shadcn/uiベース
- 参考画像 `docs/design/refs/` (Codex生成) を正とし、実装前にDirectorが1枚選定する
- フォント: 日本語可読性優先 (UIラベルは小さめでも読めること)

## 品質基準

- 初回表示 (manifest+シェル) を高速に。Lighthouse Performance / A11y 90+
- キーボードのみで全操作可能、再生チップにaria-label (キャラ名+セリフ+モデル名)
- OGP設定 (公開時にSNSでプレビューが出ること)
