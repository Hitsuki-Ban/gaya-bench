# 日本語TTSエコシステムと権利関係 調査レポート
### RPGモブNPC「ガヤボイス」商用ゲーム収録のための実務ガイド
**調査日: 2026年7月27日** / 対象: 日本語特化エンジン・参照音声の権利・API型サービス

> 本レポートの規約解釈は一次情報(公式規約ページ)に基づくが、法的助言ではない。断定できない箇所は **【要確認】** と明記した。最終判断は各権利者への照会または法務レビューを推奨する。

---

## 1. 総括

- **今日この瞬間が、日本の「声の権利」の分水嶺**である。法務省の有識者検討会は **2026年7月27日(本日)** に「人の声も肖像と同様に権利保護の対象になる」と明記した報告書案を大筋了承し、**2026年8月に報告書を公表**予定。パブリシティ権侵害が認められれば損害賠償・削除請求が可能との整理になる。現行著作権法では「声質そのもの」は保護対象外(実演は著作隣接権)だったため、これは実務上の大きな転換点。
- **「法的にセーフでも事業が消える」リスクが実証済み**。にじボイス(DMM傘下Algomatic)は日本俳優連合から計53体のキャラクターボイス削除要請を受け、同社が「法的な権利侵害は認められない」との認識を示しつつも **2026年2月4日にサービス終了**した。クラウド専業サービスへの依存は、素材ごと消滅するリスクを伴う。
- したがってガヤボイス制作の推奨ルートは **「参照音声の出所を100%クリーンにする」ことを最優先**とし、以下の3層構成が現実的:
  1. **主力**: あみたろの声素材工房 / つくよみちゃんコーパス など「AI学習・商用利用を明示的に許諾している日本語フリー声素材」を参照音声にしたローカルクローンTTS。クレジット表記のみで商用ゲーム収録可。
  2. **補完**: AivisSpeech + **ACML-1.0** ライセンスのモデル(公式モデル「コハク」「まお」等)。クレジット任意・商用自由・ローカル実行可でライセンス的に最も摩擦が少ない。
  3. **保険/比較アンカー**: VOICEPEAK 商用可能6ナレーターセット(買い切り・キャラ縛りなし・商用OK)を「絶対に揉めない基準線」として1系統確保。クラウドAPIは ElevenLabs(有料プラン) か Aivis Cloud API を1〜2個。
- **VOICEVOXは「無料商用OK」ではなく「クレジット表記付き商用OK」**。東北ずん子プロジェクト系キャラは、クレジット非表示での商用利用は **1キャラクターあたり40万円(+税)** の有償ライセンス契約が必要。ガヤは1タイトルで多数キャラを使うため、キャラ数×40万円が効いてくる。
- **絶対に避けるべき**: JVSコーパス等の「非商用限定」音声を参照音声にすること、実在声優に似せる意図での素材選定、COEIROINK生成音声を他モデルの学習データに使うこと(規約で明示禁止)。

### 2-2. 各エンジンの詳細と落とし穴

#### VOICEVOX
- ソフトウェア規約: 「商用・非商用問わず利用することができます」「VOICEVOX を利用したことがわかるクレジット表記が必要です」「作成された音声を利用する際は、各音声ライブラリの規約に従ってください」
  → 一次情報: https://voicevox.hiroshiba.jp/term/
- **キャラごとに規約が別**。ずんだもん/東北ずん子/東北きりたん/東北イタコ/四国めたん/あんこもん は東北ずん子プロジェクト(zunko.jp)の音源利用規約が適用され、**「クレジット表記をしない商用利用については、利用料を1キャラクター毎に40万円(＋消費税)で契約」**と明記。春日部つむぎ・冥鳴ひまり等はそれぞれ別規約。
  → 一次情報: https://zunko.jp/con_ongen_kiyaku.html
- クレジットの掲出位置: アプリの場合「アプリの紹介画面などに記載をお願いします。(少し探せばわかる場所に)」。表記例「VOICEVOX:ずんだもん」。ゲームならクレジット画面に確実に入れる運用でよい。
- 東北ずん子PJのキャラ利用ガイドラインには、東北6県に本社を置く企業は申請不要で無料商用利用可(自社名・住所の表記が条件)、四国めたんは四国企業、中国うさぎは中国地方企業…という地域優遇がある。
  → https://zunko.jp/guideline.html
- **【要確認】** VOICEVOX生成音声を「他の音声合成モデルの学習データ・クローン参照音声として使う」ことの可否は、ソフトウェア規約にもキャラ規約にも明示がない。zunko.jp側は「不明な点は原則お答えしておりません」というスタンス。**ベンチマークで VOICEVOX 出力をクローンの参照音声に流用するのは避けるべき**。
- キャラクターの**版権・イラスト**は音声とは別枠。ゲーム内でキャラ名やビジュアルを想起させる使い方をすると別途許諾が必要になりうる。ガヤ音声として「声だけ」使う分には音源規約の範囲。

#### AivisSpeech / Aivis Project (最有力候補)
- 「個人/法人/商用を問わず、基本的にクレジット不要で自由に使える」。ローカル実行可、CPUのみでも動作、2回目以降の起動はオフライン可。
  → https://aivis-project.com/
- **AivisHub は ACML-1.0 / ACML-NC-1.0 / CC0 の3ライセンスのみ**を選択できる仕様(2025年3月31日よりカスタムライセンスにも対応)。
- **ACML-1.0 の要点**(一次情報: https://github.com/Aivis-Project/ACML):
  - 「すべての個人利用・法人利用・非営利利用・営利利用」が可能
  - 「クレジット表記は任意です。音声合成モデルの制作者や話者のクレジット表記を行うかどうかは、あなたの判断にお任せします」
  - モデルの複製・改変・派生モデル作成も自由。再配布時はライセンス文書の添付が必要
  - 禁止: 詐欺、誹謗中傷、ディープフェイクでの偽装、反社会的利用、政治的・宗教的プロパガンダ
  - **ACML-NC-1.0 は非営利限定** → ガヤ用途では使用不可
- Aivis Cloud API 公式モデル「コハク」「まお」は ACML-1.0 で商用利用可。
- **【重要な実務リスク】** AivisHubのコミュニティ投稿モデルは、ライセンスがACMLでも「誰の声を学習したモデルか」までは保証されない。規約上はアップロード者が「第三者の知的財産権を侵害していないこと」を保証するとされているが、**実在声優の声を無断学習したモデルがACMLで公開されていた場合、下流の利用者にも実務リスク(削除要請・炎上)が及ぶ**。商用ゲームに収録するなら、**公式モデルか、自前の参照音声から作ったモデルに限定**すべき。
  → https://hub.aivis-project.com/terms-of-service

#### COEIROINK
- ソフト自体は商用・非商用問わず利用可。音声ライブラリ(キャラ)ごとに規約が異なる。
- クレジット: 「コンテンツ内、もしくは、コンテンツ概要欄のいずれかに『COEIROINK』と『合成音声名』が含まれ」ていること。
- **生成音声を「機械学習用のデータとして使用すること」は禁止**(UTAU利用は「音声の加工の範囲内」として許容)。→ ベンチで COEIROINK 出力を他モデルの参照音声にするのは**規約違反**。
- ゲーム公開時の特記: 第三者にスクショ・実況動画等の投稿を許可する場合、「そのゲーム等のコンテンツ名称が特定できる形での投稿を義務付け」る必要がある。→ **ゲームの利用規約/実況ガイドラインにこの条項を書く実装コストが発生する**。
  → 一次情報: https://coeiroink.com/terms
- 派生の **MYCOEIROINK** は自分の声でモデルを作る仕組み。自前録音ルートの受け皿として有用。

#### にじボイス (選定対象外 / 教訓として重要)
- 2024年12月提供開始 → **2026年2月4日にサービス終了**。
- 経緯: 日本俳優連合から「キャラクターボイスが組合員の声に酷似している」との申し入れ。2025年11月17日にキャラクター33体を削除、19日にさらに20体の削除要請(計53体)。Algomaticは「いずれのケースでも法的に権利侵害は認められなかった」との認識を示しつつ、事業判断として終了。
  → 一次情報: https://algomatic.jp/news/notice_nijivoice_20251121 / 報道: https://ledge.ai/articles/algomatic_nijivoice_service_end_2026_0204
- **教訓**: (a) クラウド専業サービスは素材ごと消える。(b) 「法的にセーフ」は「事業が続く」を意味しない。(c) 声の類似性の指摘は主観ベースでも実効的な圧力になる。
- **【要確認】** サービス終了前に生成済みの音声を、終了後も商用ゲームに収録し続けてよいかは公式発表から確定できなかった。同種のリスクを避けるため、**クラウド生成音声には「サービス終了後の利用継続可否」条項を必ず確認**する。

#### CoeFont
- 無料プランは営利目的での利用不可。Lite以下はクレジット「Voiced by https://CoeFont.cloud」必須。Standard以上でクレジット不要の商用利用が可能とされる(プラン説明ベース)。
- **最大の注意点**: 公開されている利用規約(coefont.cloud/maker/terms)には第2条2項として「本サービスを利用した作成された音声合成データについて生じる知的財産権等は全て当社に帰属」との規定があり、同ページの禁止事項には「商用利用する行為及び音声合成データを使用して利益を得る行為」も列挙されている。
- **【要確認】** これは CoeFont STUDIO / メイカー向けの旧規約または別系統の規約である可能性が高く、現行の有料プラン向け規約と矛盾する。**ゲームに収録する素材の権利帰属が「当社に帰属」と読める規約が生きている以上、商用ゲームのアセットソースとしては採用を見送るのが安全**。採用する場合は必ず現行の有料プラン規約を文書で取得すること。
  → https://coefont.cloud/maker/terms

#### VOICEPEAK 商用可能6ナレーターセット (AHS) — 「揉めない基準線」
- 「商用・業務利用可能な製品となっておりますので基本的に当社にご連絡なくご利用頂けます」。個人・法人・教育機関いずれも可。追加ライセンス料不要。
- 買い切り: DL版 ¥23,800 / パッケージ版 ¥29,800(税込)。vol.2 が2026年6月30日発売。
- **キャラクター設定を持たないナレーター音声**のため、キャラ利用条件の制約を受けない = クレジット表記もキャラ規約も不要。
- **【要確認】** 「他のアプリケーションへの組み込みを伴う場合は別途お問い合わせ」との記載あり。**事前レンダリングした音声ファイルをゲームアセットとして収録する**のは通常の商用利用の範囲と解されるが、**エンジンをゲームに組み込んでリアルタイム合成する場合は要問い合わせ**。ガヤ音声は事前収録なので問題ない見込み。
- 対になる「VOICEPEAK キャラクター製品シリーズ」(ずんだもん等)は**個人利用のみ**で、商用は別途ライセンスが必要。混同注意。
  → 一次情報: https://www.ah-soft.com/voice/6nare/ / https://www.ah-soft.com/commercial/voicepeak/individual/

#### Style-Bert-VITS2 (OSS)
- 日本語イントネーション精度・スタイル制御ともに評価が高く、AivisSpeechの基盤技術でもある。ローカル完結。
- **コードは AGPL-3.0**。プリセットのjvnvモデルはJVNVコーパス由来で CC BY-SA 4.0。
- **【要確認】** AGPLは「ネットワーク越しにソフトを提供する場合」にソース開示義務が生じる。**オフラインで音声ファイルを生成し、そのwavだけをゲームに同梱する運用ならAGPLの配布義務は生じない**と一般に解されるが、ゲーム本体にエンジンを組み込む場合はAGPL汚染のリスクがある。ガヤ生成パイプライン(社内ツール)としての利用が安全。
- 学習に使うコーパスのライセンスがそのまま出力の制約になる点に注意(jvnv = CC BY-SA 4.0 = 継承条件あり)。

#### さくらのAI Engine 音声合成(TTS) API (2026年2月26日提供開始)
- 国内基盤で完結するクラウドTTS。VOICEVOX音声モデル(ずんだもん、四国めたん、春日部つむぎ、冥鳴ひまり、東北ずん子、東北きりたん、東北イタコ、あんこもん)に対応。
- **すべてのVOICEVOXモデルで「VOICEVOX:キャラクター名」形式のクレジット表記が必須**。適用規約はVOICEVOXソフトウェア利用規約＋各キャラクター音源利用規約。キャラの版権・イラストは別途条件。
  → 一次情報: https://manual.sakura.ad.jp/cloud/ai-engine/05-tts-licenses.html

### 3-2. 主要素材の規約詳細

#### あみたろの声素材工房 — ガヤ用途で最も使い勝手が良い
- 商用利用: 全面OK。ただし**事後報告が必要な区分**あり。

  - **【要確認】** 「売上20万円未満の自主制作物は報告不要」という基準も示されている。**商用ゲーム(有料販売)は「企業の製品・サービス」に該当する可能性が高く、事後報告を行うのが安全**。

- **現行法の限界**: 著作権法上、演技・歌唱は「著作隣接権(実演家の権利)」で保護されるが、**「声質そのもの」は保護対象外**。そのため法務省はパブリシティ権・肖像権(人格権)の枠組みで整理を進めている。
- **実務への影響**: 判例が存在しない領域だったが、8月の報告書公表後は「人気声優の声を無断でAI模倣し、SNSに投稿して収益化する行為は権利侵害になりうる」という解釈指針が示される。**ゲーム開発でも「参照音声の出所」と「実在人物への類似性」が争点になりうる**。
- **【要確認】** 報告書は指針であって立法ではない。実際の民事訴訟でどう機能するかは今後の運用次第。8月の報告書全文が出た時点で再確認すること。

### 5-2. 実務上のガード(推奨運用)

1. **参照音声の出所台帳を作る**: 素材名 / 配布URL / 規約のURL / **規約本文のスナップショット(PDF or WARC)** / 取得日 / 適用ライセンス版 / クレジット文言 を1行1素材で記録。後日規約が変わっても「利用開始時点の規約」を立証できる。
2. **「似ている」と言われない設計にする**: 実在声優を想起させるキャラ名・宣伝文句を避ける。ピッチ/話速/フォルマントを意図的にずらす。**にじボイスの事例が示す通り、法的に権利侵害でなくても類似性の指摘は実効的な圧力になる**。
3. **クレジットはゲームのクレジット画面に確実に掲出**: VOICEVOX系「VOICEVOX:キャラ名」、COEIROINK系「COEIROINK」+合成音声名、あみたろ「音声素材：あみたろの声素材工房（https://amitaro.net/）」、つくよみちゃんは指定文言そのまま。**ガヤに複数素材を混ぜると表記漏れが起きやすいので、ビルド時にアセットのメタデータからクレジット一覧を自動生成する仕組みを推奨**。
4. **クラウド依存を最小化**: 生成済みwavをローカルに永続保管し、サービス終了時にも再生成不要な状態にしておく。**にじボイスの事例では、サービス終了後の既存生成物の扱いが公式発表から明確に読み取れなかった**。
5. **COEIROINK採用時は実況ガイドラインの整備が必要**: 「ゲーム名が特定できる形での投稿を義務付ける」条項をゲーム側の二次利用規約に書く必要がある。
6. **VOICEVOX系のコスト試算**: クレジット表記をするなら無料。しないなら1キャラ40万円+税。ガヤで10キャラ使うなら400万円。**クレジット表記を選ぶ前提で設計するのが合理的**。

### 5-3. 海外展開時の追加論点

- **EU AI Act 第50条(透明性義務)が2026年8月2日に適用開始**。AI生成の音声・映像コンテンツについて開示義務が課され、違反時は最大1,500万ユーロまたは全世界売上高の3%の制裁金。
- **【要確認】** ゲーム内のキャラクターボイスが「ディープフェイク」に該当し開示義務の対象となるかは解釈が分かれる(実在人物を模していない創作キャラの音声は対象外との解釈が有力)。**EU向けに販売する場合は法務確認必須**。
- **OpenAI TTS を使う場合は、サービス規約レベルで既に「AI生成音声である旨の開示」が求められている**。クレジット画面に「本作の一部音声はAI音声合成技術により生成されています」と記載する運用が無難。

### 5-4. 「声質の類似」以外に見落としがちな論点

- **キャラクターの版権と音声の権利は別**: VOICEVOX/COEIROINKでは、音源利用規約をクリアしても、キャラクターのイラスト・名前・設定の利用には別の許諾が必要。**ガヤで「声だけ」使うなら音源規約の範囲で足りる**が、キャラ名をクレジットに書く行為自体が版権表示になる点は留意。
- **モデルの同梱 ≠ 音声の同梱**: あみたろ等はモデル配布に制約があるが、**生成済みwavの同梱は素材利用として許諾範囲**。ゲームにTTSエンジンを組み込んでリアルタイム生成する設計にすると、途端にモデル配布ルール・AGPL等が効いてくる。**ガヤは事前レンダリングが権利面でも正解**。
- **サウンドトラック等での二次利用**: つくよみちゃんは「合成音声を素材として再配布すること」を禁止。ボイスドラマCD、音声素材集としての切り出し販売は別途確認が必要。

## 付録: 判断早見表

**Q. ガヤ音声を商用ゲームに入れる最短・最安全ルートは?**
→ 自前録音の参照音声 + ローカルのゼロショットクローンTTS。権利者ゼロ、クレジット不要、規約変更リスクなし。

**Q. 自前録音の手間を省きたい**
→ あみたろ + つくよみちゃんコーパスを参照音声に使う。クレジット表記(2件)をゲームのクレジット画面に掲出するだけ。あみたろは商用ゲームなら事後報告を推奨。

**Q. 参照音声すら用意したくない、エンジンの声をそのまま使いたい**
→ AivisSpeech + ACML-1.0モデル(公式「コハク」「まお」)。クレジット任意・商用自由。次点でVOICEVOX(クレジット必須)。

**Q. 権利面のリスクをゼロにしたい(法務が厳しい)**
→ VOICEPEAK 商用可能6ナレーターセット(買い切り・キャラ縛りなし)。ただし演技幅は狭い。

**Q. 絶対に手を出してはいけないもの**
→ JVS/JSUT音声の商用転用、AivisHubの出所不明コミュニティモデル、COEIROINK生成音声の再学習、ElevenLabs無料枠での商用生成、実在声優に似せる意図での素材選定。
