# 演技・感情表現に特化した音声データ資源 調査レポート
### ガヤボイスの「朗読っぽさ」を解消するための、権利安全な演技データ地図
**調査日: 2026年7月28日** / 前提レポート: `docs/research/ja-ecosystem-rights.md`（あみたろ・つくよみちゃん・エンジン選定・法制動向は既出のため差分のみ扱う）

> 規約解釈は一次情報に基づくが法的助言ではない。断定できない箇所は **【要確認】** と明記した。

---

## 1. 総括

- **結論から言うと、「演技データ」の世界は日本語・英語ともにほぼ全滅で、商用可の資源は片手で数えられる。** 学術系の感情コーパス（OGVC / HCUDB / CAVIARES / 声優統計コーパス音声）はほぼ全て研究目的限定、海外の主力（Expresso / EARS / ESD / NonverbalTTS / CapSpeech / ParaSpeechCaps）は**軒並み CC BY-NC 系**で商用ゲームには使えない。
- **例外は3つ。** ① **JVNV / JNV**（高道研、**CC BY-SA 4.0**、日本語・6感情・非言語発声つき・計4時間強）が唯一の「商用可の日本語感情コーパス」。② **あみたろ**（6演技スタイル×ITA424文 + 感情/戦闘系セリフ素材3,300点超、AI学習を明示許諾）。③ **AI声優**（青トキエ）の学習元音声（**中年男性・大人の女性**を埋められる。AI学習可・営利可・クレジット必須）。
- **市販の買い切り声素材集はほぼ全て「AI入力・学習」を明示禁止**しており、ここから演技データを買う道はない。**ぴた声(AHS) は EULA 第5条5項で「音声合成の研究や開発」自体を禁止**、**効果音ラボは「AI学習用データとしての利用は禁止」**、**すぱらんど も「AI等の学習素材にする」行為を禁止**。ただし効果音ラボの「ガヤ／歓声／悲鳴／戦場の叫び」は**AIを通さず完成音源としてそのままゲームに敷く**分には商用無料・クレジット不要で、**背景ざわめきレイヤの調達先としては最良**。
- **「演技指示→音声」のペアデータは、商用可のものが存在しない。** CapSpeech・ParaSpeechCaps とも NC。一方で本プロジェクトが既に採用している **Irodori-TTS v2/v3 VoiceDesign（MITライセンス、日本語キャプションで声質・感情・演技を指定）** が事実上その役割を担うので、**データを買うのではなく「キャプション文言のプロンプト辞書」を自作するのが正解**。
- **推奨ルートは「JVNV+あみたろ+AI声優+自前録音」で感情×強度のアンカー音声ライブラリを内製し、(a)スタイル転写の参照音声として使い、(b)必要なら Irodori-TTS v3 の LoRA を数時間分のデータで焼く**、の二段構え。素材収集から評価まで**実働4〜6人日**で組める規模（後述§3）。
- **最大の落とし穴は CC BY-SA の継承**。JVNV を使う場合、生成物までSA継承するかが論点になる。つくよみちゃん公式の法的整理（著作権法30条の4）を援用すれば継承不要と読めるが、**これは他者の解釈であり自社法務の確認が必須**【要確認】。継承リスクを完全に避けたいなら JVNV は「fine-tune用(b)」ではなく**参照音声(a)としてのみ**、あるいは使わずに自前録音で置き換える。

## 3. 演技例ライブラリ（スタイル転写アンカー）自作プラン

### 3-1. 設計

**目的**: 「感情 × 強度 × 声質」の3軸で、ゼロショット参照音声／スタイル転写のアンカーとなる短尺クリップ集を作る。ガヤ生成時に「怒り・中・中年男性」を指定すれば対応するアンカーwavが引ける状態にする。

**タクソノミー**（Expresso / EARS / NonverbalTTS の分類を参考に、ガヤに必要なものだけ抽出）

- **感情8種**: 平静 / 喜び / 怒り / 悲しみ / 驚き / 恐怖 / 嫌悪 / 呆れ
- **強度3段階**: 弱（つぶやき・独り言）/ 中（通常会話）/ 強（叫び・大声）
- **非言語6種**（別レイヤ）: 笑い / 泣き・すすり / 悲鳴 / うめき・呻吟 / ため息 / 息のみ（驚愕の吸気）
- **声質6種**: 少女 / 若い女性 / 大人の女性 / 少年 / 青年男性 / 中年〜老年男性

**規模**: 8感情 × 3強度 × 6声質 = 144クリップ（各3〜10秒）＋ 非言語6種 × 6声質 = 36クリップ。**計180クリップ**。

### 3-2. 素材の当てはめ

|---|---|---|---|

| 若い女性 | **つくよみちゃん**（中立）／**JVNV女性2名** | JVNVで6感情＋非言語がフル | ほぼ充足 |
| 大人の女性 | **AI声優「金苗」** | ITA読み上げのみ＝中立寄り | **自前録音 or 発注**で感情差分を追加 |
| 少年 | 該当フリー素材が乏しい（すぱらんどはAI学習禁止で使えない） | 空白 | **自前録音**必須。またはピッチシフト＋VoiceDesignで代替生成 |

**背景ざわめき（本物のガヤ）** は AI を通さず **効果音ラボ**の「ガヤ／歓声／戦場の叫び／逃げ惑う人々」をそのままミックスするのが最短・最安全（商用無料・クレジット不要）。**ただしAI学習・AI入力には一切使わないこと。**

### 3-4. 段階的な進め方（推奨）

1. **Phase 0（0.5日）**: JVNV + JNV + あみたろ6スタイルだけで「感情6種 × 3声質」の**36クリップ最小セット**を作り、スタイル転写が実際に効くか検証。効かないなら参照音声を増やしても無駄なので、ここで打ち切り判断。
2. **Phase 1（2日）**: 効いたら180クリップのフルセットへ拡張。AI声優と自前録音で声質を埋める。
3. **Phase 2（2日）**: VoiceDesign キャプション辞書を整備し、参照音声なしルート（出所リスクゼロ）と参照音声ありルートを比較。
4. **Phase 3（任意）**: それでも足りなければ **Irodori-TTS v3 の LoRA** を、あみたろ＋自前録音＋（法務OKなら）JVNV の**数時間規模**で焼く。LoRA学習手順は公開ガイドあり。RTX 4070Ti 12GB でも 500M〜600M クラスなら現実的。

## 4. リスクと要確認事項

1. **【要確認】JVNV の CC BY-SA 継承範囲**（最重要）
   - JVNV は CC BY-SA 4.0。**「学習に使ったモデル」「生成された音声」までSA継承するか**が最大の論点。
   - つくよみちゃん公式は「**著作権法30条の4が適用されるため、コーパスもソフトウェアも出力音声もCC BY-SAを継承しない**」と整理し、その条件として①音声技術の研究開発目的に限定、②元の著作物の表現の享受が目的でない、③著作権者の利益を不当に害さない、の3点を挙げている。
   - **これは他者による解釈であり、JVNVの権利者（高道研）の公式見解ではない**。商用ゲームに収録する以上、**自社法務でGOを取るか、JVNVを参照音声(a)にとどめて fine-tune(b) には使わない**のが安全側。
   - 継承すると判断した場合、クレジット表記に加えて「生成音声をCC BY-SAで公開」という現実的に不可能な義務が生じうる。**この不確実性を嫌うなら、最初から JVNV を外して自前録音で置き換える設計にする。**

2. **買い切り素材集の「AI禁止」は横断的な業界慣行**
   - ぴた声(AHS) EULA 第5条5項:「ぴた声を利用した音声合成の研究や開発等の研究結果の情報の公開、成果物の配布公開及び業務や商用での利用はできません。法人によるぴた声を利用した音声合成の研究や開発等は許諾しておりません。」→ **法人による利用は明確に不可**。
   - 効果音ラボ:「AI学習用のデータとして利用することは禁止」。
   - すぱらんど:「AI等の学習素材にするなど、本サイトの運営を著しく妨げる可能性のある行為」を禁止。
   - **「AI学習禁止」がゼロショットの参照音声（学習ではなく推論時の入力）を含むかは規約上不明**【要確認】。禁止の趣旨からすれば含むと読むのが自然で、**参照音声としても使わないのが安全**。
   - 一方で**完成音源としてゲームに直接収録するのは全て問題ない**。ガヤの背景レイヤはこちらで固める。

3. **【要確認】AI声優（青トキエ）の「個人利用の範囲内」表記**
   - 学習元音声について「学習元としたモデルの作成と公開（要クレジット）」「営利利用」が許可範囲に含まれる一方、規約冒頭に「個人利用の範囲内で利用可能」と読める記載がある。**法人・チーム開発での利用可否を権利者に照会すべき。**
   - クレジット文言は「AI声優-○○（キャラクター名）」形式。ソフトウェア（COEIROINK）出力側の音声は **AI学習禁止**なので、必ず「学習元音声」データの方を使うこと。

4. **NII IDR 系（OGVC / HCUDB / CAVIARES / STUDIES）を「検証だけ」に使う誘惑**
   - 「利用目的は研究に限ります」と明記。**商用製品の検証は研究に該当しない**。ベンチで使って本番は別素材、というやり方は規約違反かつベンチの再現性も失う。**最初から触らない。**
   - なお「研究内容によっては民間企業等の研究者にも提供可能」との記載はあるが、これは**非商用研究**の話であり商用利用の許諾ではない。

5. **声優統計コーパスの音声を「CC BY-SA だから商用OK」と誤読しない**
   - CC BY-SA なのは**音素バランス文（テキスト）のみ**。音声ファイルは別ライセンスで「主に個人での研究・分析目的でのみ無償で利用可能」「再配布禁止」。**プロ女性声優3名の喜怒の演技という魅力的な中身だが、商用ゲームには使えない。**

6. **in-the-wild データ（Laughterscape / Emilia-YODAS）の実在人物リスク**
   - 2026年7月27日の法務省検討会報告書案が「人の声も肖像と同様に権利保護の対象」と整理した直後の環境では、**YouTube等から収集された実在人物の声を学習・参照に使うことのリスクは従来より明確に高い**。CC-BY表記があっても、その表記が正しい保証も、話者本人がAI利用に同意した証拠もない。**採用しない。**

7. **Irodori-TTS の学習データが非公開**
   - モデル重みは MIT で商用可だが、**「高品質な日本語音声データセット」としか記載がなく、データセット名が公開されていない**【要確認】。にじボイスの事例（法的にセーフでも事業判断で終了）を踏まえると、**出所不明の学習データに全面依存する設計は避け、あみたろ／つくよみちゃん／自前録音といった出所の明確な参照音声と組み合わせる**か、少なくとも代替系統を1つ確保しておくべき。

8. **非言語発声（悲鳴・うめき）は権利以前に「収録が容易」**
   - 悲鳴・うめき・気合いといった非言語音は**言語能力を要求しないため、社内メンバーの自前録音で十分な品質が出る**。ガヤは明瞭度要求も低い。権利で悩むより録った方が速い、という領域が確実に存在する。

9. **クレジットの積み上がり**
   - JVNV(CC BY-SA: 帰属表示) + あみたろ(名称+URL必須) + AI声優(「AI声優-○○」必須) + つくよみちゃん(指定文言) を併用すると、クレジット画面の管理が煩雑になる。**アセットのメタデータからクレジットを自動生成する仕組み**（既出レポート§5-2-3の推奨）を、演技ライブラリのmanifestにも適用すること。
