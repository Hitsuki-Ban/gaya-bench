# 「歴史的音源（れきおん）」音源取得可否調査

調査日: 2026-07-30

対象 Issue: [#82](https://github.com/Hitsuki-Ban/gaya-bench/issues/82)

## 結論

国立国会図書館（NDL）が「インターネット公開（保護期間満了）」と表示する
「歴史的音源」は、権利上は NDL への申請なしで再利用できる。一方、NDL が
公式に提供している取得手段は **メタデータの一括ダウンロードと音源の
ウェブ再生まで**であり、音声ファイルのダウンロード手段は確認できなかった。
NDL の複写サービスも音源の複製を対象外としている。

したがって、NDL の配信を録音したり、再生用ストリームを解析・保存したりせずに
20 本以上の韻律アンカーを整備する、という本 Issue の主経路は実行不可と判断する。
`assets/prosody-anchors/` と空のメタデータ雛形は作成しない。

## 一次情報による確認

| 確認事項 | 結果 | 根拠 |
| --- | --- | --- |
| 保護期間満了資料の再利用 | 可 | NDL「[国立国会図書館の資料の二次利用](https://www.ndl.go.jp/use/reproduction)」は、デジタルコレクションで「インターネット公開（保護期間満了）」と表示される資料について、NDL への申請なしで利用できるとしている |
| 書誌メタデータの一括取得 | 可 | NDL「[オープンデータセット](https://www.ndl.go.jp/dlib/standards/opendataset)」で「歴史的音源」の TSV/XLSX が公開されている |
| オープンデータの対象 | メタデータのみ | 同ページは、データセットから参照される画像・音声データをオープンデータの対象外としている |
| NDL による音源複製 | 不可 | NDL「[よくあるご質問：複写の対象](https://www.ndl.go.jp/help/scope)」は「音源・映像の複製はできません」と明記している |
| れきおん参加館での複製・DL | 不可 | NDL の案内「[図書館で『歴史的音源』をご利用いただけます](https://rekion.dl.ndl.go.jp/static/files/5_chikyu1r.pdf)」は、館内端末での利用に加えて「複製やダウンロードはできません」と明記している |
| インターネット公開音源の UI | 再生のみ | [サンプル資料「居酒屋（二）」](https://dl.ndl.go.jp/pid/8266870)を Chromium で確認。音源名の資料ページ遷移と再生操作はあるが、ダウンロード操作はない |

サンプル資料のブラウザ通信も確認したが、再生用のトークン付き HLS 配信だけで、
公開仕様として案内された音声ファイル API は見つからなかった。これは
ダウンロード方法として採用せず、ストリームの保存・復号・録音も行っていない。

ここで重要なのは、**権利上の再利用可否**と**配信元が提供する取得手段**を分ける
ことである。前者が「可」でも、後者が提供されていなければ、プロジェクトが
説明可能な取得経路で音声バイナリを作ることはできない。

## 2026 年 2 月公開メタデータの確認

NDL 公開データ
[`dataset_202602_r_internet.zip`](https://dl.ndl.go.jp/static/files/dataset/dataset_202602_r_internet.zip)
を取得し、TSV を集計した。

- ZIP SHA-256:
  `59316685ef80ae3d50f24c1d7a486a12422aed2edc286677bee6500b413b8e6a`
- 全 6,137 件
- 全行の公開範囲: `インターネット公開`
- 今回の 4 ジャンルは全 438 件が `保護期間満了`

| ジャンル | 件数 |
| --- | ---: |
| 落語 | 259 |
| 漫談、漫才 | 22 |
| 浪曲 | 130 |
| 講談 | 27 |
| **合計** | **438** |

従来資料にある「落語・漫才・浪曲・講談 6,253 点」は館内限定を含む
れきおん全体の概数であり、インターネット公開かつ保護期間満了の候補数ではない。
公式取得経路が将来追加された場合は、この 438 件を候補母集団として再利用できる。

## 代替入手経路

### 1. Wikimedia Commons の明示ライセンス音源

現時点で、直ちにファイル取得でき、権利表示も追跡できる代替経路である。

- [二代目立花家花橘「寿限無」](https://commons.wikimedia.org/wiki/File:Jugemu_performed_by_Tachibanaya_Kakitsu_II.oga):
  12 分 49 秒。れきおんを出典とし、Commons 上で Public Domain Mark、
  `PD-old-70-expired`、`PD-Japan-audio` が明示されている。
- [現代録音「寿限無」](https://commons.wikimedia.org/wiki/File:Jugemu-ogg-henkan.ogg):
  21 秒。投稿者自身の録音で CC0。

Commons API で `rekion.dl.ndl.go.jp` を出典本文に含む File 名前空間を検索した結果は
前者 1 件のみであり、`Category:Rakugo` の音声も上記 2 件と短い発音例だけだった。
浪曲・講談・漫才の音声は確認できない。したがって、権利と取得経路は明瞭だが、
4 ジャンル 20 本以上のアンカー群には不足する。単一演目を細切れにして本数だけを
満たす運用は採らない。

### 2. NDL / HiRAC への音源提供可否の照会

NDL には [問い合わせフォーム](https://form2.ndl.go.jp/form/pub/ndl01/contact)があり、
れきおん参加館向け窓口も公開されている。公版 438 件の研究・評価用途について、
元の WAV または正規の一括提供方法があるかを照会する余地はある。

これは外部機関との調整を伴い、提供可否・費用・利用条件・所要期間が未確定である。
本調査では問い合わせを送信していない。実施する場合は別 Issue で、対象点数、
用途（韻律参照のみ）、保管方法、公開範囲を明記して進める。

### 3. 新規収録

古典演目または利用許諾済み台本を、契約した現代の話者に演じてもらい、
音源の利用範囲を明示して収録する。歴史的名人芸そのものではないが、必要な
ジャンル・演技軸・音質を設計でき、取得経路と利用条件を最も明確にできる。
20〜40 本規模を確実に作る代替案としては、現状これが最も実務的である。

## 再開条件

次のいずれかが成立した場合に限り、音源整備を再開する。

1. NDL / HiRAC が公版音源の正規ダウンロードまたは提供方法を案内する
2. Commons 等に、4 ジャンルを十分に覆う明示ライセンス音源が追加される
3. 新規収録の話者・台本・利用許諾・予算が確定する

再開時も、各クリップに出典 URL、原資料 PID、権利表示、取得日、用途
（韻律転写アンカー限定・声質クローン不可）を記録する。
